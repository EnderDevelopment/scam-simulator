# Scam Simulator

Engage in virtual scams with this immersive FiveM script.

## Features

- Purchase a PC from secret locations
- Engage in multiple scam types with different success rates and rewards

## Requirements

- FiveM server
- QB-Core framework
- oxmysql

## Installation

1. Download the script from the [GitHub repository](https://github.com/EnderDevelopment/scam-simulator)
2. Extract the files into your FiveM server's `resources` directory
3. Add `start scam-simulator` to your server.cfg file

## Usage

1. Connect to your FiveM server
2. Navigate to one of the secret locations to purchase a PC
3. Use the PC to engage in various scam activities

## Configuration

The script can be configured by editing the `config.lua` file. You can adjust the PC price, scam locations, and scam types with their respective success rates and rewards.
